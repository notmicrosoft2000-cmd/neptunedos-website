SYSTEM CORE

      
Everything a 1990s IT department would recognise.

    


    

      

        SANDBOXED FILE SYSTEM
        
Everything lives inside NEPTUNE32.

        
DIR, CD, MD, COPY, REN and DEL all
        operate inside one contained folder tree, so the shell can pretend to be dangerous
        without ever touching a file it shouldn't.

      


      

        BOOT SEQUENCE
        
A pixel-perfect setup screen.

        
Every boot and reinstall redraws the classic royal-blue MS-DOS
        installer, box-drawing characters included.

      


      

        THEME ENGINE
        
Repaint the whole console.

        
THEME AMBER swaps every colour in the shell instantly —
        no restart, no reboot.

      


      

        TUI FILE MANAGER
        
WIN or NORTON.

        
Drops you into a two-pane text interface for browsing the sandbox
        without typing a single path.

      


      

        IN-TERMINAL EDITOR
        
EDIT opens a real editor.

        
A lightweight text editor for anything living inside NEPTUNE32 —
        no external program required.

      


      

        DIAGNOSTICS
        
CHKDSK and SCANDISK narrate a disk that isn't real, with complete sincerity.

        
Volume serial numbers, byte counts, fake progress bars — the full
        ceremony of a system check that was never going to find anything wrong.
