# NeptuneDOS website

The website for NeptuneDOS 13.2 — an operating system that never left 1981.

The site is the OS: it boots, it beeps, it has a live `C:\NEPTUNE32>` console (try `THEME AMBER`), and it downloads the real builds from the [Releases](https://github.com/notmicrosoft2000-cmd/neptunedos-website/releases) page.
